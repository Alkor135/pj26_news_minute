# Проба предварительного фильтра RTS/MIX

15.10.2026, весь сентябрь 2026 по loaded_at. Версия ru-market-rules-v3.
Классификация основана только на заголовке; ценовые результаты в неё не передаются.
Это исследовательские правила, качество полноты/точности независимо не оценено.

## Лента и решения

Прочитано 37 825 исходных загрузок, после месячной дедупликации — 28 491 заголовок.
В отличие от прежнего пилота, случайная выборка 2000 до фильтра не применяется.

| Решение | Число |
|---|---:|
| Включить | 106 |
| Недостаточно информации / неоднозначная стадия | 3 974 |
| Вне основного набора | 24 411 |

Категории включённых: нефть 34, геополитика/санкции 26, ставка/инфляция 31,
валютное регулирование 4, корпоративные события 12. Возможны несколько категорий
одной новости, поэтому сумма не равна числу заголовков.

Правила требуют объект и тип события. Комментарии и ожидания выделяются отдельно
от сообщения о факте; неизвестная стадия не считается фактом. Нефтяные обзоры
котировок, обзоры иностранных индексов, переговоры о вступлении Украины в ЕС,
общий рынок газа США и целевые цены иностранных акций не проходят основной отбор.
Ормуз сам по себе не означает перебой: восстановление поставок — другая группа.
Одно слово «газ» внутри «газета» не является признаком.

Словарь компаний: SBER, GAZP, LKOH, ROSN, NVTK, GMKN, TATN, VTBR и русские
названия. Это фиксированная область исследования, не проверенный исторический
состав индекса; членство/веса не заявляются и не используются. Полная газовая
категория и зарубежная макростатистика пока не реализованы. LLM не используется:
при неоднозначности заголовок остаётся uncertain.

Уточнения v2/v3 внесены по смысловым ошибкам заголовков и независимому ревью,
без подбора порога по торговому результату. Строгая стадия существенно уменьшила
число include. Это не означает, что остальные новости не влияют на рынок:
первый фильтр может пропускать важные события. Нужна ручная проверка покрытия.

## Аналоги и реакции

Обе модели: qwen3-embedding:0.6b и bge-m3:latest. Готовые векторы переиспользованы,
недостающие получены локально. Текущий corpus_id фиксирует ровно 106 заголовков
с классификацией v3. Ценовые реакции: MIX/RTS, 5/15/30/60/120 минут, итого 1060.
Оценки по двум моделям: 2120. Порог и условия полноты сохранены.

Кандидаты имеют общую группу category:event:object:stage. Затем выбирается
ближайший текст каждой допустимой даты и пять лучших среди дат. Даты произвольные,
не обязаны идти подряд, ограничения возраста текста нет. День запроса исключён,
исход аналога должен быть известен. 20 прошлых дней — только окно калибровки фона.

**Итог: ноль отборов, прошедших все условия.** Параметры не ослаблялись.

| Причина отказа | Оценок |
|---|---:|
| Недостаточно допустимых прошлых дат | 1668 |
| Нет собственного динамического порога запроса | 342 |
| Разные направления пяти аналогов | 71 |
| Слабое сходство | 30 |
| Медиана силы ниже порога | 9 |

130 оценок имели ровно пять соседей; это оценки модель/инструмент/горизонт,
а не независимые новости. Значит, ноль отборов объясняется не только нехваткой
дней. Причины выдаются по порядку проверок, при нескольких проблемах видна первая.

Показательный случай для finplot: «Инфляция в РФ с 22 по 28 сентября составила
0,12%, годовая замедлилась до 6,25%», loaded_at 30.09.2026 19:07:03.
Qwen/MIX/30 минут нашёл пять сопоставимых заголовков от 9, 16, 17, 23 и 24 сентября.
Косинусы около 0,80–0,94; реакции −75, −325, +325, +350, −50 пунктов в порядке
сходства. Отказ mixed_directions правильный: хорошее сходство темы не гарантирует
совпадения реакции. Отчёты инфляции различаются ещё и неожиданностью относительно
ожиданий, которой в текущей БД нет.

## Проверки и просмотр

32 теста прошли. Проверены весь старый результат и новая база, разные прошлые даты,
собственная прошлая история порогов, группы совместимости, независимость от исхода
запроса, категории Qt и сохранение ручной разметки. Есть отдельный тест пяти
непоследовательных дат с промежутками в несколько месяцев. Независимое ревью
выявило смешивание восстановления/перебоев и намерений/решений; исправления
зафиксированы тестами. Проверка правил не заменяет независимую разметку реальной ленты.

```powershell
.\.venv\Scripts\python.exe russian_market.py --stage classify --history-years 0
.\.venv\Scripts\python.exe russian_market.py --month 2026-09 --history-years 0
.\.venv\Scripts\python.exe view_news_finplot.py --database data\russian_market\2026-09\reactions\reactions.sqlite3 --analogs data\russian_market\2026-09\analogs\analogs.sqlite3 --selection-mode assessments
```

Режим assessments показывает и причины отказа; режим analogs будет пустым.
В окне доступны категории, объяснения и графики каждого из пяти аналогов.
Полная RSS-лента на отдельной вкладке сохраняет все сообщения для контекста.

Файлы data/russian_market/2026-09: classification.csv (вся классификация),
review_blind.csv (до 60 примеров каждого решения без котировок), summary в JSON,
папки pilot/reactions/analogs. Поля human_decision/human_category/human_comment
пока пусты; заполненные поля неизменных заголовков сохраняются при повторном запуске.
Ручные оценки автоматически не подменяют правила и не влияют на расчёт.

Следующий обоснованный этап — проверить включения и пропуски на этой выборке,
затем расширить историю текстов на несколько месяцев. В этой пробе расширена
полнота ленты внутри сентября, а не диапазон месяцев. Отсутствие отборов не
доказывает отсутствие новостного эффекта; оно относится к данным правилам/выборке.
