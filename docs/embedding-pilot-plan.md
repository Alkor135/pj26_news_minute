# План пилотного сравнения эмбеддингов

Пользователь согласовал эксперимент: сравнить уже установленные Qwen3-Embedding
0.6B и BGE-M3 на 1–3 тысячах уникальных заголовков, сохранить векторы и показать
аналоги. Выполнение в текущем проекте; исходные базы открываются только для чтения.

## Устройство

`source/embedding_pilot.py` — чтение новостей, дедупликация, клиент Ollama,
SQLite-кэш и ранжирование; корневой `embedding_pilot.py` — командный запуск.
`source/embedding_report.py` — CSV и HTML для просмотра.
Пилот эмбеддингов использует стандартную библиотеку. Результаты в `data/embedding_pilot`.
Проверки в `tests/test_embedding_pilot.py`, временные тестовые БД в `tests`.

## Шаги

- [x] Проверить тестами нормализацию заголовков, выбор ранней загрузки,
  валидацию векторов, раздельный кэш моделей и исключение будущего из поиска.
- [x] Реализовать выборку: сентябрь 2026, 2000 заголовков, seed=42; сохранять
  источник и число повторов. Пустые/некорректные даты исключать с учётом в отчёте.
- [x] Рассчитать нормированные float32-векторы пакетами через `/api/embed`;
  checkpoint после пакета, возобновление по digest модели и версии подготовки.
  Проверять число, размерность, конечность и ненулевую норму векторов.
- [x] Сохранить измерения скорости только новых вычислений, отдельно прогрев;
  не путать чтение кэша с производительностью модели.
- [x] Для 30 запросов сохранить top-5 обеих моделей: весь месяц и прошлые
  новости с зазором 120 минут. Совпадение результатов не считать качеством.
- [x] Запустить реальные модели, проверить полноту БД и результаты поиска,
  обновить README и открыть HTML-отчёт.

## Границы проверки

Тесты должны ловить потерю раннего loaded_at при повторах, смешивание моделей,
попадание будущих записей, некорректные векторы и неверный косинусный порядок.
Близкие по смыслу перепечатки автоматически не объединяются: отчёт предупреждает
об этом. Форматы данных и часовое предположение МСК фиксируются в метаданных.
Скорость зависит от оборудования и загрузки Ollama; один прогон не рейтинг моделей.
Разметку качества выполняет человек. Торговое преимущество здесь не измеряется.

## Выполнение

15 октября 2026: шесть модульных тестов проходят; реальный прогон завершён,
сохранены 4000 векторов и 600 строк аналогов. Проверены нормы векторов,
целостность SQLite и временной зазор каждой пары past. Повторный запуск
использует по 2000 кэшированных векторов и не вызывает пересчёт.
HTML проверен в браузере. Итоги: [embedding-pilot-results.md](embedding-pilot-results.md).
