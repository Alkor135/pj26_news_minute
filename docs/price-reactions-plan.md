# Минутные котировки, реакции новостей и finplot

Продолжение согласованного исследования. Вход — после loaded_at, горизонты
5/15/30/60/120 минут. Сначала обработать ту же выборку 2000 новостей сентября,
чтобы связать реакции с уже рассчитанными эмбеддингами без новых вычислений Ollama.

## Решения

- Источник тиков — существующие ZIP MIX/RTS, только чтение. Загрузчик соседнего
  проекта quote_download использует mstime=on и добавляет искусственные доли секунды.
  Для входа исключается вся секунда loaded_at + latency; выход — последняя сделка
  строго до секунды конца горизонта. Сохранять реальный порядок строк.
- Максимальное ожидание входа/давность выхода — 60 секунд. Пробел между соседними
  тиками >120 секунд делает окно неполным. Не переносить позиции через дату.
  Проверять порядок времени, цены/объёмы, дату и структуру CSV; ничего не исправлять молча.
- OHLCV по минутам [начало, начало+1мин), без искусственного заполнения пропусков.
- Полная таблица всех новостей/инструментов/горизонтов со статусами. Знак изменения
  и нейтральная зона 50 пунктов MIX / 20 RTS — исследовательские настройки, не издержки.
- MFE/MAE и максимальный откат по тикам, ER/доля направленных закрытий по минутам.
  Нормировка по 60 минутным доходностям, известным до новости; требуется 61 подряд
  идущая закрытая свеча. Порог устойчивости: Z>=2, ER>=0.45, доля>=0.7,
  MAE и максимальный откат<=0.5*abs(изменение). Последняя предсобытийная свеча
  непосредственно предшествует минуте новости. Это ретроспективная метка, а не сигнал.
- Источник не содержит кодов срочных контрактов: флаг continuous_contract_unverified
  сохраняется для всех событий. Причинность и прибыльность не утверждаются.

- [x] `tests/test_price_reactions.py`: тесты секундной границы входа/выхода,
  пропусков, конца дня, экстремумов, свечей и отсутствия будущего в нормировке.
- [x] `source/price_data.py`: чтение ZIP и минутные свечи; `source/price_reactions.py`: метрики.

По дополнительному указанию пользователя все реализации перенесены в source;
в корне оставлены три исполняемые точки входа с прежними командами запуска.
15 тестов прошли. Независимая проверка проведена, два замечания исправлены с
проверками регрессии. Реальный пересчёт: 20 000 реакций, 15 401 полное окно,
213 устойчивых сочетаний по 146 заголовкам. Подробности: [price-reactions-results.md](price-reactions-results.md).
