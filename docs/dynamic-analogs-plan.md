# Отбор по пяти прошлым дням с динамическим порогом

Согласованные условия: пять ближайших аналогов из разных дней, все раньше дня
текущей новости, последствия каждого уже известны к loaded_at текущей новости.
Отбор аналогов по тексту до проверки знака/силы движения, без замены неудобных
примеров. Все пять знаков совпадают; медиана abs(движение)/собственный порог >=1.
ER/MAE/откаты не фильтруют новый режим. Фактическая реакция текущего запроса не
определяет его попадание в выборку и показывается только для проверки прогноза.

## Динамический фон

Предыдущие 20 доступных торговых дней, только полностью прошлые даты. Интервалы
по сетке 15 минут с теми же правилами входа/конца/пробелов, что у новостей.
Сопоставимые часы: начало в пределах ±60 минут; будни/выходные раздельно.
Сначала отбирается ближайшая по предшествующей sigma половина фона (не меньше
30 интервалов), требуется минимум 5 разных дней. Порог доходности:
`sigma_новости * Q75(abs(R_фона)/sigma_фона)`. Таким образом он меняется и с
распределением прошлых движений, и с текущей известной волатильностью.
Пункты для отображения вычисляются по последнему завершённому минутному close,
который известен к loaded_at; цена будущего входа не участвует в отборе.
Недостаточная/нулевая sigma, нулевой порог или малое число дней/интервалов => отказ.

Порог косинусного сходства — отдельный настраиваемый параметр, по умолчанию 0.5
как исследовательский ограничитель. Он не откалиброван и не является вероятностью.
Сохраняются все оценки/причины отказа, включая слабое сходство. Порог движения
не задаётся фиксированным числом пунктов, процентов или Z.

## Реализация и проверки

- [x] `source/dynamic_threshold.py`: динамический отбор; сетка и SQLite-кэш в build_analogs,
  прошлые дни, временной/волатильностный отбор и квантиль; tests/test_dynamic_analogs.py.
- [x] `source/analog_selection.py`: top-1 в каждом дне, затем top-5, оценка знаков
  и медианы, причины отказа, без доступа к исходу текущей новости.
- [x] `source/build_analogs.py` и корневой `build_analogs.py`: чтение готовых
  векторов, расчёт порогов, SQLite/CSV всех оценок, fingerprint входных данных.
- [x] `source/view_news_finplot.py`: режим по аналогам, список пяти соседей с
  датами/сходством/движением/порогом, просмотр их графиков; прежний режим сохранён.
- [x] Реальный запуск, проверки отсутствия будущего/повторных дней и влияния
  фактического исхода запроса, тесты, независимая проверка и README.

Все вспомогательные реализации в source, только исполняемые команды в корне.
Результаты data/analog_analysis, тестовые файлы только tests, файловых логов нет.
Первый прогон использует существующие 2000 заголовков и обе модели; фон котировок
дополняется августом. Он ограничен выборкой текстов, не является окончательным
бэктестом, не учитывает издержки и причинность.
