# Поиск пяти аналогов за год

Расчёт 15.10.2026. Месяц проверки — сентябрь 2026; для каждой новости поиск
ограничен интервалом от loaded_at минус один календарный год включительно до
начала дня запроса исключительно. Даты пяти аналогов произвольные, не подряд.
Исход каждого аналога должен быть известен к запросу. Прежние тематические
группы, минимум косинуса 0,5, согласие пяти знаков и медиана силы >=1 сохранены.

## История и покрытие

Запрошена RSS-история с 01.09.2025 до 01.10.2026 исключительно. Реальное начало
БД — **26.09.2025 13:24:04**, конец выбранного интервала — 30.09.2026 23:55:03.
В начале сентября 2026 доступно меньше года; программа не заполняет этот пробел.
Каждый запрос использует только доступную часть своего годового окна.

Прочитано 383 839 загрузок, две с пустым заголовком. Получено 319 441 событий
по ключу дата+нормализованный текст. Они не обязательно являются независимыми
экономическими эпизодами: перепечатка в другой день может повторять прежнее событие.
Дневная дедупликация сохраняет одинаковые тексты разных дней, месячная прежнего
пилота могла их объединять. В новом корпусе есть шесть текстов с разными датами.

Фильтр ru-market-rules-v3 оставлен без изменений: 1 242 include, 36 333 uncertain,
281 866 exclude. По категориям include: компании 173, геополитика 427, нефть 353,
ставка/инфляция 281, валюта 33; возможны несколько категорий события.

Из 1242 событий **106 — запросы сентября, 1136 — более ранняя история**.
Все 106 пары loaded_at+title точно совпадают с месячной пробой. Исторические
запросы не добавляются в статистику сентября. Модель/подготовка зафиксированы
manifest; векторы точного текста переиспользованы, недостающие рассчитаны Ollama
для Qwen3-embedding:0.6b и BGE-M3. Новые дневные ID не смешивают разные версии
эмбеддинга или тексты с разным регистром.

Реакций по истории — 12 420, из них 7 810 полные. Неполные сохранены: gap 1015,
endpoint_missing 369, entry_wait 2475, cross_day 156, no_entry 195,
missing_archive 400. По датам событий прочитаны 576 архивов, отсутствуют 38.
Неполные реакции не подставляются нулём и не становятся аналогами.

Фон: по 358 архивов каждого инструмента с 04.09.2025 по 30.09.2026;
51 463 полных интервала MIX и 38 647 RTS. Каждый порог по-прежнему использует
только предшествующие дни своего события. Настройки 20 дней/±60 минут/Q75/
волатильность не менялись. Из 1060 текущих порогов 1002 совпали со старой пробой
полностью; значение T изменилось у 53, ещё у пяти изменились только сведения
о фоне. Расширенная история дала больше доступного фона для ранних дат. Поэтому
это сравнение расширенных наборов данных, а не изолированная оценка одного эффекта.

В открытом finplot Qwen/RTS/15 первая отобранная новость: «ЦБ не будет долго
держать ключевую ставку, заявила Набиуллина», 11.09.2026 15:59:03.
Её аналоги: 20.03, 24.04, 19.06, 24.03.2026 и 19.12.2025, все с положительной
15-минутной реакцией. Порядок — по косинусу, не по дате/исходу. Прогноз вверх,
факт +150 при пороге около 304 пунктов. Условия графика не выбирались по лучшему
фактическому результату: это первая отобранная новость выбранного режима.

Годовая история устранила значительную часть нехватки аналогов, но сама по себе
не подтвердила пригодность правила для торговли. Семантическая сопоставимость
внутри широких групп также остаётся ограниченной, особенно у санкционных комментариев.
Издержки и независимый период проверки не добавлялись этим изменением.

## Проверки и воспроизведение

37 тестов прошли, включая проверку всей готовой годовой базы: граница года,
исключение текущего/будущих дней, завершённые исходы, разные даты, тематическая
совместимость, собственная история порогов, период запросов и query_count.
Проверены 29 февраля, одинаковые тексты разных дат, регистрозависимое
переиспользование векторов и подпись периода в Qt. Независимое ревью не выявило
новых существенных ошибок. Исходные RSS/ZIP и прежние результаты не изменялись.

```powershell
.\.venv\Scripts\python.exe russian_market.py --month 2026-09 --history-years 1
.\.venv\Scripts\python.exe view_news_finplot.py --database data\russian_market\2026-09_year1\reactions\reactions.sqlite3 --analogs data\russian_market\2026-09_year1\analogs\analogs.sqlite3 --instrument RTS --horizon 15 --selection-mode analogs
```

Результаты: data/russian_market/2026-09_year1, структура classification.csv,
classification_summary.json, review_blind.csv, pilot/reactions/analogs и
finplot_year.png. `--history-years 0` воспроизводит старый месячный режим.
Ручные поля review_blind.csv пока не размечены; качество фильтра не объявляется
проверенным по одним синтетическим тестам.
